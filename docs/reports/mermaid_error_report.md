# Mermaid レンダリングエラー調査レポート

チャット中に発生した Mermaid のレンダリングエラーおよび「爆弾アイコン」の大量表示について、原因の特定と対策を完了しました。

## 1. エラー概要
- **現象A (Mermaid Render Error)**: `timeline` ダイアグラムが正常に表示されず、エラーメッセージが表示される。
- **現象B (爆弾アイコンの表示)**: チャット画面の左下に「Syntax error in text」というメッセージと爆弾アイコンが複数表示される。

## 2. 原因調査
### 現象Aの原因: `timeline` における時刻の扱い
Mermaid の `timeline` ダイアグラムでは、期間（Period）の部分にコロン `:` を含む文字列（例: `10:00`）を使用する場合、それを**ダブルクォートで囲む**必要があります。
今回のログでは `10:00 : 京都駅着` のように記述されていたため、パーサーが時刻を正しく解釈できずエラーとなっていました。

### 現象Bの原因: Mermaid のデフォルトエラー表示
Mermaid は構文エラーを検出すると、内部的にエラーを示す SVG（爆弾アイコン）を DOM に直接挿入する動作をします。
VisionArk のフロントエンドでは既に独自のエラーハンドリングを行っていますが、Mermaid 自身のデフォルトの警告 UI が抑制されていなかったため、サイドエフェクトとして爆弾アイコンが表示されていました。

## 3. 実施した修正
- **フロントエンドの修正**: `Mermaid.tsx` において、Mermaid 初期化時に `suppressErrorRendering: true` を設定しました。これにより、Mermaid のライブラリが独自の警告 UI を DOM に挿入するのを防ぎ、VisionArk 側のクリーンなエラーメッセージのみが表示されるようになります。

## 4. 今後の対策・推奨事項
- **AI/開発者への推奨**:
    - `timeline` を使用する際は、時刻やコロンを含むラベルにはダブルクォートを使用してください。
    - 例: `10:00 : ...` → `"10:00" : ...`
- **今後の動作**:
    - 万が一構文エラーが発生しても、爆弾アイコンが表示されることはなく、コンポーネント内にエラー内容が表示されるようになります。
