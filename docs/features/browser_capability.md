# 🌐 Agent Browser Capability

VisionArk のエージェントは、Playwright を使用してリアルタイムに Web ページを操作し、情報を取得したりスクリーンショットを撮影したりする機能を備えています。

## 概要

エージェントは `BrowserManager` サービスを介して、分離されたブラウザコンテキストを使用します。これにより、ユーザー間およびセッション間でのデータの干渉を防ぎながら、高速なブラウジング操作を実現しています。

## 🛠️ 提供されるツール

エージェントは以下の 4 つのツールを使用してブラウザを操作します。

### 1. `browser_open`
指定された URL をブラウザで開きます。
- **機能**: ページの読み込みを待ち、タイトルや主要なテキストコンテンツ、メタデータを取得します。
- **セキュリティ**: URL の安全性を確認し、不正なスキームをブロックします。

### 2. `browser_click`
ページ上の要素をクリックします。
- **引数**: CSS セレクターまたはテキスト（ボタン名など）。
- **動作**: 要素の存在を確認してからクリックし、実行後のページの状態（URLの変化など）を返します。

### 3. `browser_fill`
入力フォームにテキストを入力します。
- **引数**: セレクターおよび入力する文字列。
- **動作**: 指定された入力フィールドに値をセットし、必要に応じて Enter キーをシミュレートします。

### 4. `browser_screenshot`
現在のブラウザ画面のスクリーンショットを撮影します。
- **保存先**: `data/users/{user_id}/projects/{project_id}/artifacts/browser/`
- **Gemini 連携**: 撮影した画像は Gemini の File API に自動的にアップロードされ、マルチモーダルな文脈理解に使用されます。

## 🏗️ サービス設計

### BrowserManager
- **ライフサイクル**: 必要に応じてブラウザを起動し、一定期間アクティビティがない場合に自動的にクローズします。
- **隔離**: ユーザー ID とセッション ID に基づいて個別。

## 🔐 セキュリティとデータ隔離

- **ユーザー隔離**: 全てのブラウザ操作で生成されるデータ（クッキー、キャッシュ、スクリーンショット）は、`utils.paths` を使用してユーザーごとに厳密に分離されたディレクトリに保存されます。
- **パス管理**: `secure_path_join` により、ディレクトリトラバーサル攻撃を防止しています。

## ⚙️ 環境構築 (Docker)

ブラウザ機能を使用するには、バックエンドコンテナに Playwright と Chromium のバイナリが必要です。
`core/backend/Dockerfile` にて自動的にインストールされるよう構成されています。
