# Proposal F: Define and Visualize Operational Metrics

## Status
Proposed

## Priority
P1

## Objectives
Quantitatively judge whether the value of orchestration is being realized.

## Details
-   Metrics examples:
    -   Run success rate / failure types.
    -   Tool call count per response.
    -   Remand rate in verification.
    -   Resume success rate from interruption.

## Expected Benefits
-   Data-driven prioritization of improvements.

## Scope & Risks
-   **Scope**: Medium. Aggregation queries, APIs, and dashboards.
-   **Risk**: Cost of agreeing on measurement definitions.
