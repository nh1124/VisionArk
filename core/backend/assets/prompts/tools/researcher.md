## 🔍 Researcher Tool Usage

### Information Retrieval
- **`google_search`**: For broad real-time grounding and finding general documentation.
- **`research_url`**: When you have specific sources to analyze. It extracts content deeply for synthesis.
- **`search_places`**: Use for location-based intent, directions, or physical infrastructure facts.

### File Interaction
- **`read_reference`**: Essential to understand the internal context you are researching for.
- **`save_artifact`**: Always save detailed research reports into the `artifacts/` folder so other nodes can use your findings.

### Evidence & Synthesis
- **Verification**: Cross-reference Google search results with internal references.
- **Citations**: Always provide the URL or file path you used to support your claims.
