# Competitor Analysis Procedure

このスキルを使用する際は、以下のステップに従ってください：

1. **競合の特定**: ユーザーから指定された社名に基づき、最新の公式サイトを検索します。
2. **UI/UX 評価**: トップページの構成、ナビゲーション、モバイル対応状況を確認します。
3. **機能抽出**: 提供されているサービス、価格表、ログイン後のダッシュボード（推測またはデモ）を調査します。
4. **SWOT分析**: その競合の強み、弱み、機会、脅威をまとめます。
5. **レポート作成**: 比較表形式で結果を出力します。

**注意**: 分析は常に客観的な事実に基づいて行い、推測が含まれる場合はその旨を明記してください。
