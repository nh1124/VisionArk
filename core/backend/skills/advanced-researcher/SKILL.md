# Advanced Researcher Procedure

複雑な調査依頼を受けた際は、以下のステップに従って自律的にリサーチを遂行してください：

1. **多角的検索**: 
   - `google_search` を用いて、異なるキーワードや視点で複数回の検索を行います。
   - 信頼性の高いソース（公式サイト、技術ドキュメント、査読済み論文など）を優先的に選択します。

2. **コンテンツ解析**:
   - 選択した複数のURLに対し `read_url_content` を実行し、詳細な情報を抽出します。
   - 専門用語や数値データ、比較ポイントを特に注視してください。

3. **情報の統合と整理**:
   - 収集した情報を整理し、矛盾点がないか確認します。
   - 必要に応じて `search_knowledge` を実行し、過去のプロジェクト知識との関連性を確認してください。

4. **構造化レポートの作成**:
   - `save_artifact` を用いて、Markdown形式のリサーチレポートを生成します。
   - レポートには以下の項目を含めてください：
     - 調査の目的と背景
     - 主要な知見のまとめ
     - 比較表やメリット・デメリットの整理
     - 参照ソース一覧
     - 次のステップへの提言

5. **フィードバックの反映**:
   - ユーザーからの追加質問がある場合は、再度ステップ1に戻って深掘り調査を行います。
