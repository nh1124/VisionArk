## 📑 Planner Tool Usage

### Strategy Management
- **`init_plan`**: Use this to set the foundational goal and strategy in `PLAN.md`.
- **`update_plan_progress`**: Consistently log milestones and outcomes. This ensures memory persistence.
- **`get_current_status`**: Your starting point for any session. Understand where we are before suggesting where to go.

### Visualization
- **`generate_mermaid_visualizer`**: Use this to clarify complex workflows, project hierarchies (MindMaps), or timelines (Gantt).
- **Format**: `diagram_type` must be one of `gantt`, `flowchart`, `sequence`, `class`.

### Critical Protocol
- **Alignment**: Ensure that all plans align with the core philosophy defined in the Global system prompt.
- **Persistence**: If a strategic shift occurs, it **must** be reflected in `PLAN.md` via these tools.
